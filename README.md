AirDraw AI Ultimate Pro is a browser-based AI drawing application that allows users to draw in the air using hand tracking powered by MediaPipe Hands.

## ✨ Features

- 🖐️ Real-time hand tracking
- ✏️ Air drawing
- 🧽 Gesture-based eraser
- 🌈 Rainbow drawing mode
- 💡 Hologram effects
- 🔥 Particle effects
- 🔷 AI shape recognition
- ↩️ Undo / Redo
- 💾 PNG export
- 🖼 SVG export
- 🎤 Voice commands
- 📱 Responsive canvas
- 🤖 Experimental AI learning system

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/airdraw-ai.git
```

Open the project folder:

```bash
cd airdraw-ai
```

Run a local server (recommended):

```bash
python -m http.server
```

Then open:

```
http://localhost:8000
```

## Controls

| Gesture | Action |
|----------|--------|
| 👆 Thumb + Index | Draw |
| ✌️ Index + Middle | Eraser |
| ✋ Open Hand | Pause |
| 🤏 Pinch | Brush Size |
| 🤌 Thumb + Pinky | Change Color |
